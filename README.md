# EduMaster — Online Course Platform

A complete, modern, and responsive **Online Learning Platform** website built with **HTML5** and **CSS3** for a 1st-year B.Tech Web Development college project.

---

## Project Description

**EduMaster** is an online education platform inspired by real-world e-learning websites. Designed with a crisp **Royal Blue** and **Purple** gradient palette over clean white and light grey surfaces, the website showcases course categories, featured courses, expert mentors, platform statistics, student reviews, an About Us overview, newsletter signup, and a contact page.

---

## Objectives

- Design and structure a complete multi-section educational website using semantic **HTML5**.
- Style a consistent, modern UI/UX using pure **CSS3** (Flexbox, CSS Grid, CSS variables, transitions, animations, and responsive media queries) without Bootstrap or CSS frameworks.
- Ensure smooth navigation and full responsiveness across desktop, laptop, tablet, and mobile screens.
- Keep the codebase clean, modular, well-commented, and beginner-friendly.

---

## Technologies Used

- **HTML5** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`)
- **CSS3** (Custom Properties, CSS Grid, Flexbox, Keyframe Animations, Media Queries, `:target` Modals)
- **Google Fonts** (`Plus Jakarta Sans` & `Inter`)
- **Font Awesome 6 Free** (Icons via CDN)
- **Custom SVG Icons & PNG Assets**

---

## Key Features

- **Responsive Sticky Navbar**: Logo, 6 section links, *Login* and *Get Started* modals, and a pure-CSS mobile hamburger menu.
- **Hero Section**: Bold value proposition, dual CTA buttons, learning highlights, and custom classroom illustration.
- **8 Course Categories**: Programming, Web Development, AI, Data Science, Graphic Design, Business, Cyber Security, and Digital Marketing.
- **8 Featured Courses**: Python, HTML & CSS, Java, AI, Data Science, Machine Learning, UI/UX Design, and Full Stack Development with pricing, ratings, duration, and *Enroll Now* action.
- **Why Choose Us**: 6 highlight cards covering instructors, flexibility, projects, certificates, affordability, and lifetime access.
- **Instructors & Testimonials**: 4 instructor profiles and 4 student review cards.
- **Statistics Banner**: 10,000+ Students, 100+ Courses, 50+ Expert Instructors, 95% Student Satisfaction.
- **About Us, Newsletter & Contact**: Mission/Vision cards, email subscription bar, validated contact form, and structured 4-column footer.

## Instructions to Run Using VS Code Live Server

1. Open **Visual Studio Code**.
2. Click **File > Open Folder...** and select the `EduMaster` folder (`c:\Users\HP\OneDrive\Desktop\web development\EduMaster`).
3. Open the **Extensions** panel (`Ctrl + Shift + X`), search for **Live Server** (by *Ritwick Dey*), and install it.
4. Open `index.html`, then click **Go Live** in the bottom-right corner (or right-click inside `index.html` and select **Open with Live Server**).
5. Your browser will open the live website automatically (for example at `http://127.0.0.1:5500/index.html`).
